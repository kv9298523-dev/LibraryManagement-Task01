# Library Management Console App

**Task 01 – .NET Development (C#)**

## Project Description
A simple Library Management Console Application developed using C# and .NET. It manages book details and displays them in a readable format.

## Features
- Add books to the library.
- Display book details.
- Validate book title and author.
- Validate book price.
- Handle invalid input using exceptions.

## Technologies Used
- C#
- .NET 8.0

## Project Structure
- `Program.cs`
- `Book.cs`
- `Library.cs`
- `LibraryManagement.csproj`

## How to Run
1. Install the .NET 8 SDK.
2. Open this project folder in Terminal.
3. Run:

```bash
dotnet restore
dotnet build
dotnet run
```

## Concepts Covered
- Classes and Objects
- Properties instead of public fields
- Constructors
- Input Validation
- Exception Handling
- Lists and Collections
